			=================================================================
						Dict Category Data Type
			=================================================================
=>The purpose of Dict Category Data Type is that "To Store the Data in the form of (Key,Value) in single Object".
=>The Data Type in Dict Category is 'dict'.
=>Here dict is one of the Pre-Defined Class and Treated as Dict Category.
=>To Store the Data in the form of (Key,Value)  in dict object, we must Use a symbolic notation called Curly Braces and (Key,Values) Must separated Comma.
=>Syntax:	DictObject={Key1:Val1, Key2:Val2,.....,Key-n:Val-n}
	=>Here Key1,Key2,....Key-n are Called Values of Key and They Must be Unique.
	=>Here Val1,Val2,....,Val-n are Called Values of Value and they May or May not be Unique.
=>An Object of Dict Maintains Insertion Order.
=>On the Object of Dict, we can't Perform Indexing and Slicing Operations bcoz Values of Key Itself acts as Indices.
=>An Object of Dict belongs to Mutable bcoz we are able Update the Value of Value  by passing Existing Value of Key.
=>In (Key,value) , The Values of Key are Immutable and Values of Value are Mutable.
=>W.r.t Dict Class, we can create Two Types of Dict objects. They are
					1. Empty Dict
					2. Non-Empty Dict
--------------------------------------------------------
1. Empty Dict
--------------------------------------------------------
=>An Empty Dict is One  which does not contain any (Key,Value) and whose length is 0.
=>Syntax-1:   DictObj={}
=>Syntax-2:	DictObj=dict()
--------------------------------------------------------
2. Non-Empty Dict
--------------------------------------------------------
=>A Non-Empty Dict is One  which contains  (Key,Value)  and whose length is >0.
=>Syntax:	DictObject={Key1:Val1, Key2:Val2,.....,Key-n:Val-n}
****************************************************************
Syntax for Adding (Key,Value) to Empty / Non-Empty Dict Object--Most Imp
****************************************************************
			DictObj[Key1]=Val1
			DictObj[Key2]=Val2
			--------------------------
			DictObj[Key-n]=Val-n
=>Here Key1,Key2,....Key-n are Called Values of Key and They Must be Unique.
=>Here Val1,Val2,....,Val-n are Called Values of Value and they May or May not be Unique.
****************************************************************
