			=========================================================
				Pre-Defined Functions in Dict--Most Imp
			=========================================================
=>We know that on the object of Dict, we can perform the following Operations.
			1. We get the value of Value by passing Value of Key
			2. We can Modify the Old value of Value by passing Exist Value of Key
			3. We can add (Key,Value) to Dict Object.

=>Along with above Operations, we can Perform Various Other Operations  by using Pre-Defined Functions in dict Object.
=>The Pre-Defined Functions in dict Object are
----------------------------------------------------------------------------------------------------------------------------------------------------------------
1.clear()
----------------------------------------------------------------------------------------------------------------------------------------------------------------
=>Syntax:   DictObj.clear()
=>This Function is used for Removing all the(Key,Value) from Dict Object.
=>When we call clear() on empty dict then we get None as Result OR Space as Result
------------------------------------
Examples
------------------------------------
>>> d1={10:1.2,20:2.3,30:4.5,40:5.6}
>>> print(d1,type(d1))
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'>
>>> len(d1)
4
>>> d1.clear()
>>> print(d1,type(d1))
{} <class 'dict'>
>>> len(d1)
0
>>> print(d1.clear())
None
-------------------------------
>>> print({}.clear())
None
>>> print(dict().clear())
None
----------------------------------------------------------------------------------------------------------------------------------------------------------------
2. copy()
----------------------------------------------------------------------------------------------------------------------------------------------------------------
=>Syntax: DictObj2=DictObj1.copy()
=>This Function is used for Copying the content of DictObj1 into Dictobj2( Implements Shallow Copy).
--------------------------------------
Examples
--------------------------------------
>>> d1={10:1.2,20:2.3,30:4.5,40:5.6}
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431680
>>>
>>> d2=d1.copy()  
>>> print(d2,type(d2),id(d2))
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762624192
>>> d1[10]=11.2
>>> d2[50]=3.2
>>> print(d1,type(d1),id(d1))
{10: 11.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431680
>>> print(d2,type(d2),id(d2))
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6, 50: 3.2} <class 'dict'> 2541762624192
------------------------
>>> d1={10:1.2,20:2.3,30:4.5,40:5.6}
>>> d3=d1 # Deep Copy
>>> print(d3,type(d3),id(d3))
{10: 11.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431680
>>> d1[10]=0.5
>>> print(d1,type(d1),id(d1))
{10: 0.5, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431680
>>> print(d3,type(d3),id(d3))
{10: 0.5, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431680
>>> d3[20]=11.5
>>> print(d1,type(d1),id(d1))
{10: 0.5, 20: 11.5, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431680
>>> print(d3,type(d3),id(d3))
{10: 0.5, 20: 11.5, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431680

3. pop(key)
----------------------------------------------------------------------------------------------------------------------------------------------------------------
=>Syntax:   Dictobj.pop(Key)
=>This Function is used for Removing the (Key,Value) from Dict Object Based On Value of Key.
=>If the Value of Key Does not Exist then we get KeyError.
--------------------------------
Examples
--------------------------------
>>> d1={10:1.2,20:2.3,30:4.5,40:5.6}
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431488
>>> d1.pop(20)
2.3
>>> print(d1,type(d1),id(d1))
{10: 1.2, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431488
>>> d1.pop(30)
4.5
>>> print(d1,type(d1),id(d1))
{10: 1.2, 40: 5.6} <class 'dict'> 2541762431488
>>> d1.pop(300)--------------KeyError: 300
>>> {}.pop(10)------------------KeyError: 10
>>> dict().pop(10)-------------KeyError: 10
----------------------------------------------------------------------------------------------------------------------------------------------------------------
4. popitem()
----------------------------------------------------------------------------------------------------------------------------------------------------------------
=>Syntax:   Dictobj.popitem()
=>This Function is used for Removing the Last (Key,Value) from Dict Object.
=>If we call this function on empty dict then we get KeyError.
----------------------------------
Examples
----------------------------------
>>> d1={10:1.2,20:2.3,30:4.5,40:5.6}
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762367680
>>> d1.popitem()
(40, 5.6)
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.3, 30: 4.5} <class 'dict'> 2541762367680
>>> d1.popitem()
(30, 4.5)
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.3} <class 'dict'> 2541762367680
>>> d1.popitem()
(20, 2.3)
>>> print(d1,type(d1),id(d1))
{10: 1.2} <class 'dict'> 2541762367680
>>> d1.popitem()
(10, 1.2)
>>> print(d1,type(d1),id(d1))
{} <class 'dict'> 2541762367680
>>> d1.popitem()------------------>KeyError: 'popitem(): dictionary is empty'

5. get()--Most Imp
----------------------------------------------------------------------------------------------------------------------------------------------------------------
=>Syntax:   Value=DictObj.get(Key)
=>This Function is used for Getting the Value of Value By passing Value of Key.
=>if the value of Key does not Exist then we get None as Result
					OR
Syntax:             DictObj[Key]			
=>This Syntax Gives Value of Value By passing Value of Key.
=>If the Value of Key does not Exist then we get KeyError.
--------------------------
Examples
--------------------------
>>> d1={10:1.2,20:2.3,30:4.5,40:5.6}
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762431744
>>> val=d1.get(10)
>>> print(val)
1.2
>>> val=d1.get(20)
>>> print(val)
2.3
>>> val=d1.get(30)
>>> print(val)
4.5
>>> val=d1.get(300)
>>> print(val)
None
---------------------------------------
>>> d1={10:1.2,20:2.3,30:4.5,40:5.6}
>>> print(d1)
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6}
>>> d1[10]
1.2
>>> d1[20]
2.3
>>> d1[30]
4.5
>>> d1[300]---------------------KeyError: 300

8. items()
----------------------------------------------------------------------------------------------------------------------------------------------------------------
=>Syntax:  Varname=DictObj.items()
=>This Function is used for Obtaining (Key,Value) from Dict Object and placed in LHS Varname and whose type is <class, dict_items>
-------------------------------------
Examples
-------------------------------------

>>> print(d1)
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6}
>>> kvs=d1.items()

9. update()
----------------------------------------------------------------------------------------------------------------------------------------------------------------
=>Syntax:   Dictobj1.update(Dictobj2)
=>This Function is used for Merging  the Content of DictObj2 with DictObj1.
-------------------------------------
Examples
-------------------------------------
>>> d1={10:1.2,20:2.3}
>>> d2={30:4.5,40:5.6}
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.3} <class 'dict'> 2541762620160
>>> print(d2,type(d2),id(d2))
{30: 4.5, 40: 5.6} <class 'dict'> 2541790561344
>>>
>>> d1.update(d2)
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.3, 30: 4.5, 40: 5.6} <class 'dict'> 2541762620160
---------------------------------
>>> d1={10:1.2,20:2.3}
>>> d2={20:4.5,40:5.6}
>>>
>>> d1.update(d2)
>>> print(d1,type(d1))
{10: 1.2, 20: 4.5, 40: 5.6} <class 'dict'>
----------------------------------------
>>> d1={10:1.2,20:2.3}
>>> d2={10:14.5,20:15.6}
>>>
>>> d2.update(d1)
>>> print(d2,type(d2))
{10: 1.2, 20: 2.3} <class 'dict'>
